# XAUUSD Signal System v6.0

Новая система сигналов по золоту (XAUUSD), построенная строго по 12-блочному
курсу трейдинга (свечи → таймфреймы → тренд → S/R → пробой+ретест → объём →
EMA → свечные паттерны → графические фигуры → вход/SL/TP). Заменяет старую
"5 фильтров одновременно" версию — там сигнал требовал 5 случайных совпадений
разом и почти никогда не срабатывал.

Архитектура:

```
TradingView (Pine-индикатор XAUUSD_TA_Master_v6.pine)
   считает весь TA и шлёт alert() с JSON сетапа
        │  webhook (HTTPS POST)
        ▼
webhook_relay.py (Python, Flask)
   проверяет секрет → спрашивает Claude "согласован ли сетап логически"
        │  если подтверждено
        ▼
Telegram-бот → сообщение вам в чат
```

Claude в этой схеме **не видит график** — только те же структурированные поля,
что посчитал Pine (тренд/уровень/тип сетапа/объём/фигура). Это доп. проверка
на внутренние противоречия (например "двойная вершина" + "LONG" одновременно),
а не независимый визуальный анализ. Не ждите от этого слоя роста винрейта до
75-85% — ни один код этого не гарантирует; реалистичная цель для системы на
классическом TA — 40-55% винрейт при R:R около 1:2, что прибыльно при
дисциплинированном риск-менеджменте.

**Перед тем как доверять сигналам деньгами: минимум 2-4 недели вести бумажный
журнал (Blocks 11-12 курса — "смотри реальные сделки и делай выводы") и
сверять, что сигналы совпадают с тем, что вы видите на графике вручную.**

## 1. Настройка Pine-индикатора в TradingView

1. Откройте `XAUUSD_TA_Master_v6.pine`, скопируйте код в Pine Editor на
   TradingView (график XAUUSD, таймфрейм M15 рекомендуется).
2. В настройках индикатора (группа "АЛЕРТ / ИНТЕГРАЦИЯ") задайте свой
   **Секрет вебхука** — любую случайную строку. Она же пойдёт в `.env`
   как `WEBHOOK_SECRET`.
3. Создайте алерт (Alert) на условие `LongSetupOK` или прямо на индикатор
   в целом (Any alert() function call) — именно этот вариант нужен, чтобы
   срабатывали и LONG, и SHORT алерты с их JSON-сообщениями.
4. В поле Webhook URL укажите публичный адрес вашего сервиса:
   `https://ваш-домен/webhook`.
5. ⚠️ Алерты на вебхук по кастомным индикаторам требуют платного плана
   TradingView (Essential и выше) — на Basic (бесплатном) плане это не
   работает.

## 2. Telegram-бот

1. В Telegram напишите `@BotFather` → `/newbot` → следуйте инструкциям →
   получите токен вида `123456:ABC-DEF...`. Это `TELEGRAM_BOT_TOKEN`.
2. Напишите своему новому боту любое сообщение (иначе он не сможет писать вам).
3. Узнайте свой `chat_id`: откройте
   `https://api.telegram.org/bot<TOKEN>/getUpdates` в браузере после того,
   как написали боту — в JSON будет `"chat":{"id": ЧИСЛО, ...}`. Это
   `TELEGRAM_CHAT_ID`.

## 3. Запуск сервиса

```bash
cd xauusd_signal_system
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # заполните TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID,
                                 # ANTHROPIC_API_KEY, WEBHOOK_SECRET
python webhook_relay.py
```

По умолчанию слушает `http://0.0.0.0:5000/webhook`.

## 4. Публичный доступ (нужен TradingView, чтобы достучаться до вебхука)

- **Для теста**: `ngrok http 5000` → используйте выданный `https://...ngrok...`
  URL в настройках алерта TradingView.
- **Для постоянной работы**: разверните на любом хостинге с публичным HTTPS —
  Render.com, Railway.app, Fly.io, обычный VPS + nginx/Caddy. Главное — сервис
  должен работать 24/7, иначе сигналы будут теряться, пока он выключен.

## 5. Проверка без TradingView

```bash
curl -X POST http://localhost:5000/webhook \
  -H "Content-Type: application/json" \
  -d '{"secret":"REPLACE_ME","symbol":"XAUUSD","dir":"LONG","setup":"Пробой+Ретест","entry":3345.2,"sl":3335.2,"tp":3365.2,"trend":"UP","volRatio":1.5,"volOK":true,"pattern":"нет","bonus":2}'
```

Если всё настроено — придёт сообщение в Telegram и `webhook_relay.py`
выведет лог с вердиктом Claude.

## 6. Журнал сигналов

Каждый входящий сетап (подтверждённый и отклонённый) пишется в
`signals_log.jsonl` — по этому файлу удобно раз в неделю (аналог "Блока 12 —
что делать дальше") смотреть статистику: сколько сигналов, сколько отклонил
ИИ и почему, и вручную сверять исходы (TP/SL) для честной оценки винрейта.
